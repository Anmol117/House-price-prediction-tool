# House Price Prediction Tool

A machine learning project to predict house prices using regression models, built with Python and scikit-learn, trained on a Kaggle housing dataset.

## 🚧 Project Status: Planning Phase

This project is currently in the design and planning stage. Implementation is starting soon. See the docs below for the full plan.

## 🎯 Goal

Predict house prices based on features such as location, square footage, number of bedrooms/bathrooms, and other property characteristics, using supervised regression techniques.

## 🛠️ Tech Stack

- **Language:** Python
- **ML Library:** scikit-learn
- **Data:** pandas, numpy
- **Visualization:** matplotlib / seaborn *(planned)*
- **Dataset:** [Kaggle - House Prices dataset](https://www.kaggle.com/) *(link to be updated with the exact dataset used)*
